# Auto-Fleet - Automotive Management Platform

Auto-Fleet is a comprehensive white-label platform for automotive businesses, providing solutions for car inspections, appointment bookings, AI valuations, auctions, and inventory management.

## Features

- **Dealer Management System (DMS)**: Centralize dealership operations with unified dashboard
- **Vehicle Inspection Suite**: Comprehensive digital vehicle assessment tools
- **AI Car Valuation Engine**: Instant, intelligent market valuations
- **Photo & 360 Capture Studio**: Professional imagery tools for vehicle listings
- **Auction Platform**: Run dealer auctions anytime, anywhere
- **AI Damage Detection**: Automatic detection of vehicle damage
- **Seller Lead Booking**: Simplified seller scheduling and intake
- **Analytics & Reports**: Real-time performance metrics and reporting
- **Website Enhancement & Digital Marketing**: SEO-ready integration for online presence
- **Self-Listing Portal**: Empower sellers to upload vehicle details directly

## Technology Stack

- **Frontend**: Next.js, React, TypeScript, Tailwind CSS
- **UI Components**: Shadcn UI
- **Styling**: Tailwind CSS with custom configurations
- **Icons**: Lucide React
- **Deployment**: Vercel/Netlify

## Getting Started

### Prerequisites

- Node.js 16.x or higher
- npm or yarn

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/yourusername/auto-fleet.git
   cd auto-fleet
   ```

2. Install dependencies:
   ```bash
   npm install
   # or
   yarn install
   ```

3. Run the development server:
   ```bash
   npm run dev
   # or
   yarn dev
   ```

4. Open [http://localhost:3000](http://localhost:3000) in your browser to see the application.
