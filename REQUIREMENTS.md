# Auto-Fleet Website Requirements Document

## Overview
This document outlines the requirements and specifications for the Auto-Fleet website, an automotive management platform that provides comprehensive solutions for car dealerships, inspections, valuations, and inventory management.

## Design Requirements

### Header Section
- **Branding**: 
  - Display "Automotive Management Platform" in a clearly readable, larger widget size
  - Remove "The CompleteAutomotive Management Platform" text
  - Slim down overall header size for better user experience
  
- **Visual Elements**:
  - Add 3 key images in the header right-hand side:
    1. Web Dashboard View
    2. Mobile View LPV (Lead Processing View)
    3. Inspection View
  - Remove the 3 feature boxes (AI-Powered, Scalable, Secure)
  - Remove buttons 'Book Free Demo' & 'Explore Features'

- **Navigation**:
  - Make buttons hover at top of page when scrolling down
  - Ensure consistent navigation experience across desktop and mobile

### 2nd Section (Feature Highlights)
- **Content**:
  - Add sub-heading "Explore Our Services"
  - Remove the line about mobile solution: "Managing your dealership on the go doesn't get any easier or faster than our fully integrated mobile solution. Oversee your deals, upload inventory, run vehicle history reports, communicate with customers, and more, right from your phone."
  
- **UI/UX**:
  - Ensure buttons are visible on first glance (Desktop + Mobile View)
  - Add hover effects to buttons for better interactivity
  - Maintain scrollable feature buttons

### 3rd Section
- **Content**:
  - Completely remove/hide 'WHAT WE DO' section

### 4th Section (How We Do It)
- Keep as is - no changes required

### 5th Section (Services in Action)
- **Content**:
  - Replace 3 static boxes with multiple scrollable videos/demos
  - Include demonstrations of:
    1. Masking Technology
    2. AI Valuation
    3. Inspection Module
    4. Dashboard Overview
    5. Mobile Application
  - Use screen recordings for authentic representation

### Global Changes
- **Navigation**:
  - Add a 'Back to Top' button to each Module Section
  - Button should scroll back to list of Feature Buttons (2nd Section)
  - Add floating 'Back to Top' button that appears when scrolling down

- **Typography**:
  - Make text BOLD in correct spots in each Module's Text
  - Automatically highlight key terms like 'AI', 'dashboard', 'real-time', etc.

## Technical Requirements
- Responsive design for all screen sizes
- Optimized image loading for performance
- Smooth scrolling behavior for navigation
- Hover states for interactive elements
- Accessibility compliance

## Implementation Notes
- The Book Demo functionality should be preserved
- All images should have appropriate alt text
- Video thumbnails should have play button overlays
- Maintain consistent styling throughout the site
- Ensure all interactive elements have appropriate hover/focus states
